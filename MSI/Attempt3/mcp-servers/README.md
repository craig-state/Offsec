# MegaCorpAI MCP Code Review Servers

MCP-based code review tools for the AI DevOps platform.

## Tools

- **code_formatter** - Format source code according to MegaCorpAI style guide
- **lint_checker** - Check for linting issues and style violations
- **security_scanner** - Scan for security vulnerabilities
- **doc_generator** - Generate documentation for source files

## Deployment

Tools are deployed via mcpo proxy on the code review server.
Configuration in `mcpo-config.json`.
